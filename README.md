# Vulnerability Assessment & Penetration Testing Lab

## Overview
This project demonstrates basic vulnerability assessment, risk analysis, documentation, and reporting using open-source cybersecurity tools.

## Tools Used
- Kali Linux (WSL)
- OpenVAS / GVM
- Nmap
- Nikto
- Metasploit
- MobSF
- Burp Suite
